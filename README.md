# FoodExpress - Advanced DevOps Project

## Project Objective
Build and deploy a food delivery application using
DevOps tools and AWS.

## Technologies

- Linux
- Git
- GitHub
- Python Flask
- React
- PostgreSQL
- Redis
- RabbitMQ
- Docker
- Jenkins
- Terraform
- Ansible
- SonarQube
- Trivy
- AWS ECR
- Kubernetes
- Helm
- Argo CD
- Prometheus
- Grafana
- Loki

## Project Workflow
Developer -> GitHub -> Jenkins -> Tests ->
SonarQube -> Trivy -> Docker -> ECR ->
Kubernetes -> Prometheus -> Grafana
